Partner and sponsor logos for the home page.

Only add a logo when that organisation has agreed to be shown as an INUKA partner or sponsor,
and use the logo file they give you (most organisations have brand rules for how their logo may be used).

File names expected by the database (change `logoUrl` in Prisma Studio if you use other names):
  alu.png  minema.png  mineduc.png  rema.png  mastercard-foundation.png  red-cross.png
  alight.png  unicef.png  save-the-children.png  inkomoko.png  world-vision.png

Tips: transparent PNG or SVG, about 400 px wide, cropped close to the logo, under 60 KB.
Logos are shown in full colour and slide one by one on the home page (5 at a time on a computer).
Added so far: alu, minema, mastercard-foundation, red-cross, save-the-children, world-vision, inkomoko, unicef.
Still missing: mineduc, rema, alight (their name is shown as text until the file is added).
